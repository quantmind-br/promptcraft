6. No platform-specific code paths - pyperclip handles all platform differences
7. Clipboard operations don't block or timeout command execution

### Cross-Platform Considerations
Para implementar funcionalidade cross-platform robusta:
- **Windows:** Suporte para cmd e PowerShell - pyperclip usa win32clipboard ou tkinter como fallback
- **macOS:** Suporte para Terminal - pyperclip usa pbcopy/pbpaste
- **Linux:** Suporte para distribuições principais - pyperclip usa xclip/xsel como backends
- **Fallback Strategy:** Quando clipboard falha, sugerir uso da flag --stdout já implementada
- **Error Handling:** Usar try-catch específico para PyperclipException e outros erros de clipboard
- **Performance:** Clipboard operations devem ser non-blocking e respeitar limite de 150ms

### Click Framework Integration Specifications
Para integração com o framework Click existente:
1. **Error Display:** Usar `click.secho()` com cores apropriadas para mensagens de erro/aviso
2. **Warning Color:** Implementar cor de aviso (amarelo) para mensagens de clipboard indisponível
3. **Message Format:** Seguir padrão estabelecido: "⚠️ Clipboard unavailable, use --stdout instead"
4. **Integration Point:** Modificar pontos onde pyperclip.copy() é chamado atualmente
5. **Fallback Behavior:** Integrar com funcionalidade --stdout já existente

### Error Handling Requirements
- **Exception Types:** Capturar PyperclipException, OSError, e outras exceções relacionadas
- **Fallback Behavior:** Quando clipboard falha, não terminar programa - sugerir alternativa
- **User Guidance:** Mensagem clara direcionando usuário para solução (--stdout flag)
- **Logging:** Sem logging necessário para esta funcionalidade simples
- **Recovery:** Aplicação deve continuar funcionando mesmo com clipboard indisponível

### Performance Considerations
- **Timeout Protection:** Implementar timeout para operações de clipboard (max 100ms)
- **Non-blocking:** Clipboard operations não devem bloquear execução principal
- **Memory Usage:** Minimizar uso de memória durante operações de clipboard
- **Platform Detection:** Evitar detecção manual de plataforma - deixar pyperclip handle
