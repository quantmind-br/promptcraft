# Documentation scope

The current user guide is the [repository README](../README.md). The current implementation is described in [architecture.md](architecture.md).

The older planning documents (`brief.md`, `prd.md`, `front-end-spec.md`, nested `architecture/` and `prd/`, `stories/`, `qa/` and the root QA gate) are retained as historical project records. Their language, packaging instructions, technology choices, web/full-stack proposals and acceptance results are **not current build requirements or user instructions**. They must not be used to restore removed runtime dependencies.

Current development uses Go, Cobra, Bubble Tea, Go tests and the Go CI workflow. No legacy implementation is needed to build, install, use or test PromptCraft.
